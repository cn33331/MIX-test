# UART_debug_plugin 串口调试插件

## 插件概述

UART_debug_plugin 是一个专业的串口通信调试工具，提供串口扫描、自动连接、数据收发等功能。基于PyQt6开发，采用事件驱动架构，支持多线程串口操作，保证界面流畅响应。

## 主要功能

### 1. 串口管理

- **自动扫描**：自动扫描系统中可用的串口设备
- **手动输入**：支持手动输入串口地址
- **串口信息**：显示串口设备描述信息
- **参数配置**：配置波特率、数据位、校验位、停止位

### 2. 连接控制

- **一键连接/断开**：便捷的连接状态切换
- **自动重连**：连接断开后自动尝试重连（可选）
- **状态显示**：实时显示连接状态

### 3. 数据通信

- **文本发送**：发送文本数据到串口
- **实时接收**：实时显示串口接收的数据
- **编码支持**：支持UTF-8编码
- **换行处理**：支持添加或不添加换行符发送

### 4. 日志系统

- **实时日志**：显示所有串口通信数据
- **时间戳**：显示每条消息的时间
- **清空功能**：支持清空日志显示
- **右键菜单**：便捷的操作菜单

## 核心模块

### UartManager (`uart_manager.py`)

串口管理核心类，负责所有串口操作：

```python
class UartManager:
    def __init__(self, callback=None)
    def scan_ports() -> list                           # 扫描可用串口
    def connect(port, baudrate, bytesize, parity, stopbits, auto_reconnect=False) -> bool
    def disconnect()                                    # 断开连接
    def is_connected() -> bool                        # 检查连接状态
    def send(data) -> bool                            # 发送数据
```

**主要特性**：

- 使用pySerial库进行串口通信
- 独立接收线程，避免阻塞
- 回调函数机制处理接收数据
- 自动重连机制
- 线程安全的UI更新

### 工作原理

```
┌─────────────────┐
│   主线程        │
│  (PyQt UI)      │
└────────┬────────┘
         │ 回调函数
         ▼
┌─────────────────┐
│  接收线程        │
│  - 持续读取串口  │
│  - 数据缓冲     │
│  - 触发回调     │
└─────────────────┘
```

## 串口参数说明

- 19200

- 57600
- 115200（常用）
- 230400

- 921600

### 数据位 (Data Bits)

- 5
- 6

### 校验位 (Parity)

- 无 (None/N)
- 奇校验 (Odd/O)
- 偶校验 (Even/E)

### 停止位 (Stop Bits)

- 1（常用）
- 1.5
- 2

## 使用方法

### 1. 扫描串口

- 点击"刷新串口"按钮
- 从下拉列表中选择目标设备
- 或选择"手动输入串口地址"输入自定义地址

### 2. 配置参数

- 设置波特率（通常为115200）
- 设置数据位（通常为8）
- 设置校验位（通常为无）
- 设置停止位（通常为1）

### 3. 连接设备

- 点击"连接"按钮
- 等待连接成功
- 按钮文字变为"断开"

### 4. 发送数据

- 在发送框输入要发送的文本
- 点击"发送"按钮或按回车键
- 数据发送到串口设备

### 5. 接收数据

- 串口接收到的数据自动显示在日志区域
- 每条消息带有时间戳

## 技术特点

- **事件驱动**：采用回调函数机制处理接收数据
- **多线程**：接收操作在独立线程中执行
- **线程安全**：使用Qt QueuedConnection确保UI更新安全
- **自动重连**：连接断开时可自动重连
- **资源管理**：正确关闭串口连接

### 数据流

```
串口设备 ──(数据)──> 接收线程 ──(回调)──> UartManager ──(信号)──> UI
     │
     │                          │
     └──(发送)─────────────────────┘
```

插件包含虚拟串口创建工具（`uart/uart_debug_Virtual.py`），用于在没有硬件串口的情况下测试串口通信。

### 使用虚拟串口

2. 创建一对虚拟串口（如COM5-COM6）
3. 一个串口连接本插件
4. 另一个串口连接调试工具或终端

## 故障排除

### 找不到串口

- 检查设备是否正确连接
- 检查设备驱动是否安装
- 尝试刷新串口列表
- 使用手动输入地址功能

### 连接失败

- 确认串口未被其他程序占用
- 检查串口参数是否正确
- 尝试使用管理员权限运行

### 数据接收不到

- 确认对方设备正在发送数据
- 检查波特率等参数是否匹配
- 确认连接正常建立

### 发送失败

- 检查连接是否正常
- 确认串口参数设置正确

## 开发扩展

### 添加协议解析

可以在 `uart_manager.py` 中添加协议解析功能：

```python
class ProtocolUartManager(UartManager):
    def _process_received_data(self, data):
        """自定义协议解析"""
        # 解析自定义协议
        if data.startswith('#'):
            # 命令帧处理
            self._handle_command(data)
        elif data.startswith('$'):
            # 数据帧处理
            self._handle_data(data)
```

### 添加十六进制显示

```python
def format_hex_display(data):
    """格式化十六进制显示"""
    hex_str = data.hex()
    formatted = ' '.join(hex_str[i:i+2] for i in range(0, len(hex_str), 2))
    return f"[HEX] {formatted}"
```

## 注意事项

- 连接串口前确认设备参数设置正确
- 断开连接前确保数据发送完成
- 使用完毕后及时断开连接释放资源
- 避免在发送过程中拔掉串口设备
