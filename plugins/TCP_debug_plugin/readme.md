# TCP_debug_plugin TCP调试插件

## 插件概述

TCP_debug_plugin 是一个功能全面的TCP网络调试工具，提供TCP服务器和TCP客户端功能，支持同时运行和双向通信。基于PyQt6开发，采用多线程架构保证UI响应性。

## 主要功能

### 1. TCP服务器

- **多客户端支持**：支持同时连接多个客户端
- **广播发送**：向所有已连接客户端发送消息
- **实时状态显示**：显示连接状态和在线客户端数量
- **连接日志**：记录客户端连接和断开事件

### 2. TCP客户端

- **服务器连接**：连接到远程TCP服务器
- **自动重连**：连接断开后自动重连（可选）
- **数据收发**：实时发送和接收数据
- **状态监控**：显示连接状态和错误信息

### 3. 通信功能

- **文本消息**：支持发送和接收文本消息
- **实时显示**：实时显示所有通信数据
- **发送历史**：保存发送的消息记录
- **清空日志**：支持清空通信日志

### 4. 配置选项

- **端口配置**：自定义服务器监听端口
- **地址配置**：配置服务器地址和端口
- **字符编码**：支持UTF-8编码处理

## 核心模块

### TCP服务器工作线程 (`TCPServerWorker`)

负责TCP服务器的所有后台工作：

```python
class TCPServerWorker(QObject):
    # 信号定义
    message_received = pyqtSignal(str)      # 收到消息
    client_connected = pyqtSignal(str)      # 客户端连接
    client_disconnected = pyqtSignal(str)   # 客户端断开
    error_occurred = pyqtSignal(str)        # 错误发生
    status_changed = pyqtSignal(bool)       # 状态变化

    # 主要方法
    def start()                              # 启动服务器
    def stop()                               # 停止服务器
    def send_to_all(message) -> bool        # 向所有客户端发送
```

**工作原理**：

- 使用标准`socket`库创建TCP服务器
- 启动独立线程监听客户端连接
- 为每个客户端分配独立线程处理通信
- 通过PyQt信号将事件传递到主线程

### TCP客户端工作线程 (`TCPClientWorker`)

负责TCP客户端的所有后台工作：

```python
class TCPClientWorker(QObject):
    # 信号定义
    message_received = pyqtSignal(str)      # 收到消息
    connected = pyqtSignal(bool)            # 连接状态变化
    error_occurred = pyqtSignal(str)        # 错误发生

    # 主要方法
    def connect_to_server()                  # 连接到服务器
    def send_message(message) -> bool       # 发送消息
    def disconnect()                          # 断开连接
```

## 使用方法

### 1. 启动TCP服务器

1. 设置服务器监听地址和端口
2. 点击"启动"按钮
3. 服务器状态变为"运行中"
4. 等待客户端连接

### 2. 连接到TCP服务器

1. 输入服务器地址和端口
2. 点击"连接"按钮
3. 客户端状态变为"已连接"
4. 开始接收服务器消息

### 3. 发送消息

- 服务器端：向所有已连接客户端广播消息
- 客户端端：向服务器发送消息

### 4. 监控通信

- 所有发送和接收的消息都会显示在日志区域
- 消息格式：
  - `>>` 开头表示发送的消息
  - `<<` 开头表示接收的消息

## 技术特点

- **多线程架构**：网络操作在独立线程中执行，不阻塞UI
- **线程安全**：使用PyQt信号槽机制确保线程安全
- **异常处理**：完善的异常捕获和处理机制
- **超时控制**：socket设置超时避免永久阻塞
- **资源管理**：正确关闭所有socket连接

## 注意事项

- 服务器和客户端可以同时运行
- 发送消息时确保连接正常
- 关闭插件时会自动断开所有连接
- 日志显示使用等宽字体确保对齐

## 故障排除

### 连接失败

- 检查服务器地址和端口是否正确
- 确认服务器已启动
- 检查防火墙设置

### 消息显示乱码

- 确保发送和接收使用相同的编码（UTF-8）
- 检查数据是否包含非ASCII字符

### 客户端断开

- 检查网络连接是否稳定
- 确认服务器仍在运行
- 查看日志中的错误信息

## 开发扩展

### 添加新协议支持

可以继承 `TCPServerWorker` 或 `TCPClientWorker` 实现自定义协议：

```python
class MyProtocolServer(TCPServerWorker):
    def _handle_client(self, client_socket, addr):
        # 自定义协议处理逻辑
        while self.running:
            data = client_socket.recv(1024)
            # 解析自定义协议...
            self.message_received.emit(f"收到自定义数据包")
```

### 添加十六进制显示

```python
def format_hex(data):
    """将数据格式化为十六进制显示"""
    hex_str = data.hex()
    return ' '.join(hex_str[i:i+2] for i in range(0, len(hex_str), 2))
```
